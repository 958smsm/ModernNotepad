# Smart-feature behavior

Smart features are optional, debounced, cancellable, and advisory. Writing-assistance checks, duplicate detection, spell checking, and the traditional grammar analyzer are local. Grammar analysis can also use OpenAI, a local Python worker, or Google Cloud Natural Language. Analysis returns spans and counts; it does not modify document characters.

## Smart Coloring

Grammar analysis has five directly selectable modes. All return the same `GrammarAnalysis` contract: `ColoredSpan` entries plus counts keyed by `GrammarCategory`.

**Logic & Traditional NLP** uses `GrammarColorAnalyzer` with small built-in dictionaries and suffix/context rules. It is immediate, offline, and requires no external runtime.

**OpenAI** — preserves the original `OpenAiGrammarAnalyzer` behavior and uses `OPENAI_API_KEY`.

The additional modes are:

- **Python spaCy** — `PythonGrammarAnalyzer` starts a persistent Python worker and uses spaCy POS/dependency annotations. The IPC transport is selectable between Windows **Named Pipes** and named **Shared Memory**. The default model is `en_core_web_sm`; override it with `MODERNNOTEPAD_SPACY_MODEL`.
- **Python NLTK** — the same persistent worker/IPC choices are used with NLTK `pos_tag`. Noun subject/object roles are inferred from the tagged sentence because NLTK's POS tagger does not provide dependency edges.
- **Google Cloud Natural Language** — `GoogleCloudGrammarAnalyzer` calls the v1 `documents:analyzeSyntax` endpoint with `UTF16` offsets, then maps returned POS/dependency data back to the editor's local token spans.

Run `scripts/setup-grammar-providers.ps1` to install the optional Python packages, the spaCy English model, and NLTK's English perceptron tagger data. `MODERNNOTEPAD_PYTHON` can point to a specific `python.exe`; `MODERNNOTEPAD_GRAMMAR_WORKER` can override the worker script path.

Google Cloud authentication uses `GOOGLE_CLOUD_NL_API_KEY` or `GOOGLE_API_KEY`. The key is read from the environment and is not written to Modern Notepad settings.

If any selected external mode fails, `AnalysisCoordinator` records a warning, writes redacted diagnostic details to `%LOCALAPPDATA%\ModernNotepad\grammar-provider-error.log`, and uses Logic & Traditional NLP for that pass so editing remains usable. Known OpenAI and Google API-key values are redacted.

Plain-text save uses the underlying characters only. RTF save may retain Smart Coloring as normal foreground formatting; duplicate highlights are removed before RTF serialization.

## Duplicate detection

The detector reports:

- a non-stop-word repeated more than once in one sentence;
- words meeting the configured paragraph or document threshold;
- duplicate normalized sentences, ignoring case and most punctuation.

Relaxed mode suppresses common function words. Strict mode includes them. Stable finding IDs allow individual warnings to be ignored.

## Writing assistant

Rules currently include:

- a compact list of common English misspellings;
- `could/should/would of` and `irregardless` suggestions;
- simple `a`/`an` checks;
- multiple consecutive spaces;
- lowercase sentence starts;
- configurable long sentences;
- likely `be + participle` passive-voice patterns.

These are intentionally conservative and lightweight. They are suggestions, not proof of an error.

## Statistics

- Reading time: 200 words/minute.
- Readability: approximate Flesch Reading Ease using a lightweight vowel-group syllable estimate.
- Grammar counts: counts generated by the active grammar mode/provider using the same category keys.

Readability and grammar-category statistics are English-oriented.
