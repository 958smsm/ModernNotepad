# Smart-feature behavior

Smart features are optional, debounced, cancellable, and advisory. All non-AI checks are local. AI grammar mode is the only feature that sends the current document text to a cloud API. Analysis returns spans and counts; it does not modify document characters.

## Smart Coloring

Grammar analysis has two selectable modes. Both return the same `GrammarAnalysis` contract: `ColoredSpan` entries plus counts keyed by `GrammarCategory`.

**Logic & Traditional NLP** uses `GrammarColorAnalyzer` with small built-in dictionaries and suffix/context rules:

- pronouns, prepositions, and conjunctions use closed word sets;
- common verbs plus `-ing`, `-ed`, `-ize`, `-ise`, and `-ify` rules;
- adverbs use common forms and `-ly`;
- adjectives use common forms and selected suffixes;
- remaining tokens before the first likely verb become subject/noun; remaining tokens after it become object/noun.

**AI** uses `OpenAiGrammarAnalyzer` with OpenAI `gpt-5.4-mini`. The app tokenizes locally first, marks target tokens with stable IDs, sends text context to the Responses API, validates that every target ID is classified exactly once, and maps IDs back to the original local character spans. This keeps the editor-facing output format identical to Traditional mode. AI mode requires `OPENAI_API_KEY`.

Traditional mode gives immediate offline feedback with no model download, but it is not a syntactic parser. AI mode uses remote model classification and can also make mistakes. Ambiguous words, non-English text, headings, fragments, and specialized vocabulary can be classified incorrectly in either mode.

Plain-text save uses the underlying characters only. RTF save may retain Smart Coloring as normal foreground formatting; duplicate highlights are removed before RTF serialization.

## Duplicate detection

The detector reports:

- a non-stop-word repeated more than once in one sentence;
- words meeting the configured paragraph or document threshold;
- duplicate normalized sentences, ignoring case and most punctuation.

Relaxed mode suppresses common function words. Strict mode includes them. Stable finding IDs allow individual warnings to be ignored.

## Writing assistant

Rules currently include:

- a compact list of common English misspellings;
- `could/should/would of` and `irregardless` suggestions;
- simple `a`/`an` checks;
- multiple consecutive spaces;
- lowercase sentence starts;
- configurable long sentences;
- likely `be + participle` passive-voice patterns.

These are intentionally conservative and lightweight. They are suggestions, not proof of an error.

## Statistics

- Reading time: 200 words/minute.
- Readability: approximate Flesch Reading Ease using a lightweight vowel-group syllable estimate.
- Grammar counts: counts generated by the selected grammar provider (Traditional or AI) using the same category keys.

Readability and grammar-category statistics are English-oriented.
